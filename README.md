# Landing Page Website

This is my **first manual web development project**, created as part of my learning journey with **Masynctech Coding School**.

The project is a modern **Landing Page Website** built using **HTML, CSS, and Bootstrap**. I created this project to apply my front-end development knowledge and gain practical experience in building a complete webpage from scratch.

### 🛠️ Technologies Used

* **HTML** – for webpage structure and content
* **CSS** – for styling and visual design
* **Bootstrap** – for responsive layouts and reusable components

### 🎯 Project Purpose

The main purpose of this project was to practice front-end development, understand responsive web design, and improve my ability to create clean and well-structured websites.

This project marks an important milestone in my web development learning journey with **Masynctech Coding School**.
